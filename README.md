# Business Website – Week 4 Project

This repository contains a **complete responsive business website** developed as part of **Week 4 – Complete Web Development Project**.

The goal of this project was to design, develop, and deploy a fully functional multi-page business website using core web technologies.

---

## 🔹 Project Overview

This website represents a **professional services business** offering consulting, development, and digital solutions.  
It includes multiple pages, responsive layout, form validation, optimized assets, and clean UI design.

---

## 🔹 Technologies Used

- **HTML5** – Semantic page structure
- **CSS3** – Responsive design, layout, and styling
- **JavaScript** – Form validation and interactivity
- **Git & GitHub** – Version control and deployment

---

## 🔹 Website Pages

- `index.html` – Home page with hero section and overview
- `about.html` – Company information and team section
- `services.html` – Business services with visual cards
- `contact.html` – Contact form with client-side validation

---

## 🔹 Features Implemented

- Fully responsive design (mobile, tablet, desktop)
- Navigation between multiple pages
- Contact form with JavaScript validation
- Optimized images and assets
- Clean folder structure
- Modern UI using consistent color palette
- Deployed using GitHub Pages

## 🔹 Learning Outcomes

- Understanding website architecture and planning
- Implementing responsive design principles
- Using JavaScript for real-world form validation
- Managing assets and optimizing performance
- Deploying a complete project on GitHub
